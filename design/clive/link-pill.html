Status pill

The pill at the top of every Church Drive app, and the one for the website dashboard. It starts as Clive's round button (his colour cloud, his white mark), widens into the pill, and the cloud keeps drifting behind it. This page runs the real rules: the same states, timings, easing and drawing as the Android code in core/.../LinkRefresh.kt, on a clock you can slow down.

Spec

Every number the app uses. Lengths are dp (1 dp = 1 CSS px at 1×). Easing "standard" is Material's FastOutSlowIn, cubic-bezier(0.4, 0, 0.2, 1).
