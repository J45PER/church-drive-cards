# Clive colour names

GENERATED by `tools/gen-clive-colours.mjs` from `design/clive/cards.json` (`entity_colours`). Do not edit by hand.

One list of names for every colour the apps and the dashboards use. A dashboard card's `color` (and `alert_color`, `color_template`, `list_color`) is one of these names; the apps, the watch, the satellites and the Home Assistant cards all resolve it to the same five colours. Use a name, never a hex code, so a change to the palette changes everything.

Each name has five colours: Colour (the thing's own), Dark (the ground), Accent (pulled towards Clive's purple), Light (highlight) and Deep (shadow).

## Changing a colour

The palettes live in Home Assistant (the Church Drive integration keeps them; the colours below are what it ships). A change made there reaches the apps and the dashboards straight away, with no app update: `church_drive.set_palette` (key, name, five colours; administrators) or the `church_drive/colours/set` command. The apps and dashboards read `church_drive/colours` and follow the revision on `sensor.church_drive_colours`; the glow of the Clive cards on the phone, watch and satellite comes from the same sensor through `script.clive_show_card`. A colour a card names directly in code (a hex in a card's own style) is not a palette colour and only changes with a release.

## Status

Status keeps its fixed meaning everywhere: `ok` is fine, `warn` needs attention, `bad` is wrong. A card for any entity turns to these when something is wrong, then goes back to its own name.
